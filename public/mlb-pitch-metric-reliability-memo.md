## この記事で確かめたいこと

投手の評価では、球種ごとの成績をよく見ます。「この投手のスライダーは空振りが取れている」「このチェンジアップは今年よく抑えた」といった話です。こうした数字は、来季の起用、球種の配分の見直し、トレードやスカウティングの判断に使われます。

ただ、そこで使うのは **去年の数字** で、判断したいのは **来年のこと** です。去年の数字が良かったのが「その球種が本当に良いから」なのか、「たまたまそういう年だったから」なのかで、判断の重みは大きく変わります。

そこでこの記事では、MLB の公開データを使って、次の問いに数字で答えます。

> ある投手のある球種について、今年の成績は、来年の同じ投手・同じ球種の成績をどれだけ言い当てるか。
> それは指標（空振り率、run value など）によってどれくらい違うか。

先に結論の図を載せ、そのあと用語、測り方、結果の読み方、使い方の順に説明します。

![同じ投手・同じ球種の翌年との相関](https://raw.githubusercontent.com/yasumorishima/mlb-data-pipeline/master/docs/images/pitch_metric_yoy_ja.png)

図の見方は後の節で説明しますが、一言でいうと **青の空振り率は翌年にもよく残り、赤の run value はあまり残らない** という結果です。

## 用語の説明

Baseball Savant（MLB の公式データサイト）は、投手ごと・球種ごとに次のような数字を公開しています。この記事ではそのうち 5 つを使います。

| 指標 | 意味 |
|---|---|
| 使用率 | その投手が投げた球のうち、その球種が占める割合 |
| 空振り率 | 打者がスイングしたうち、空振りだった割合 |
| 被 xwOBA | その球種を打たれたときの「打球の質」を、打球の速さと角度から出塁・長打の期待値として表したもの。実際にヒットになったかどうかではなく、どんな打球を打たれたかで決まる |
| 強い打球の割合 | 打たれた打球のうち、打球速度が 95 マイル（約 153 km/h）以上だった割合 |
| run value / 100 球 | その球種を投げた結果、失点をどれだけ防いだか（増やしたか）を得点に換算し、100 球あたりにしたもの。ストライク・ボール、ヒット・アウトなど 1 球ごとの結果をすべて足し合わせる。この記事の値はプラスほど投手にとって良い |

run value は「結局その球種で何点防いだか」を 1 つの数字で表すので、球種の評価の総合点としてよく使われます。この記事で一番伝えたいのは、**その総合点が 1 年分では翌年にあまり残らない** ということです。

## 「翌年との相関」とは

同じ投手・同じ球種を、続く 2 シーズンで 1 組にして並べます。たとえば「ある投手のスライダーの 2023 年」と「同じ投手のスライダーの 2024 年」で 1 組です。こうした組をたくさん集めて、1 年目の値と 2 年目の値の相関を取ります。

- 相関が 1 に近い：今年良かった球種は来年もほぼ同じくらい良い。今年の数字をそのまま来年の見込みとして使える
- 相関が 0 に近い：今年良かったかどうかは、来年とほとんど関係がない。今年の数字は「そういう年だった」以上のことをほとんど言っていない

相関の数字だけだと感覚がつかみにくいので、後の節では「今年上位 20% に入った球種が、来年も上位 20% に残る割合」も出しています。

## 測り方

### データ

- Baseball Savant の球種別成績、2017〜2025 年。自分で公開しているデータセット（Hugging Face `yasumorishima/mlb-stats` の `marts/mart_scouting_reliability`）から計算しています
- どちらの年も 100 球以上投げた組だけを使いました。対象は 8,022 組です
- 進行中の 2026 年は入れていません

### 球種ごとの平均を引いてから比べる

スライダーはもともと空振りが多く、シンカーは少ない、というように、球種によって数字の水準が大きく違います。これをそのまま相関に入れると、「スライダーは毎年スライダーだから空振りが多い」という球種の違いだけで相関が高く出てしまいます。

知りたいのは「同じスライダーの中で、この投手のスライダーは良い方か」が翌年も続くかどうかです。そこで、**その年のその球種の平均を引いた値**（たとえば「スライダー全体の平均より空振り率が何ポイント高いか」）で相関を取りました。スライダーはスライダー同士、チェンジアップはチェンジアップ同士で比べる、スカウティングと同じ比べ方です。

### 球数で分ける

投げた球数が少ないと、数字は偶然でぶれやすくなります。そこで組を、**2 シーズンのうち少ない方の球数** で 4 つの帯に分けました。100〜199 球は、中継ぎ投手の 3 番目の球種くらいの量です。800 球以上は、先発投手の主な球種くらいの量です。

## 結果

### 翌年との相関（球種内）

| 指標 | 100〜199 球 | 200〜399 | 400〜799 | 800 以上 |
|---|---|---|---|---|
| 使用率 | 0.79 | 0.81 | 0.87 | 0.84 |
| 空振り率 | 0.53 | 0.63 | 0.70 | 0.74 |
| 被 xwOBA | 0.26 | 0.34 | 0.46 | 0.53 |
| 強い打球の割合 | 0.20 | 0.28 | 0.38 | 0.43 |
| run value / 100 球 | 0.09 | 0.17 | 0.25 | 0.35 |
| 組の数 | 3,063 | 2,997 | 1,561 | 401 |

読み取れることは 3 つです。

1. **どの指標も、球数が多いほど翌年に残りやすい**。球数が少ないほど偶然のぶれが大きいので、これは予想どおりです
2. **指標による差は、球数による差よりも大きい**。100〜199 球の空振り率（0.53）は、800 球以上の run value（0.35）より翌年に残ります
3. **run value は、800 球以上投げた球種でも 0.35**。先発投手の主な球種くらい投げても、1 年分の run value では翌年の見込みとしては弱い、ということです

使用率が高いのは、投手が球種の配分を年ごとに大きく変えないためで、「良し悪し」の指標ではありません。参考として載せています。

### 「上位 20% が翌年も上位 20% に残る割合」で見ると

相関を、もう少し直感的な形にしてみます。各年・各球種の中で、指標の良い方から上位 20% に入った球種を選び、翌年も上位 20% に入っていた割合を数えました（被 xwOBA は低いほど良い、として並べています）。偶然だけなら、残る割合は 20% です。

| 指標 | 100 球以上の全組 | 400 球以上の組 |
|---|---|---|
| 空振り率 | 50% | 58% |
| 被 xwOBA | 38% | 44% |
| run value / 100 球 | 28% | 33% |

400 球以上投げた球種で見ても、run value で上位 20% に入った球種のうち、翌年も上位 20% に残ったのは 3 つに 1 つです。同じ条件で、翌年は下半分まで落ちた球種も 34% ありました。空振り率では、翌年も上位 20% に残ったのが 58%、下半分まで落ちたのは 12% でした。

### なぜ run value は残りにくいのか

この記事では原因を分解していないので、ここは考えられる理由として書きます。run value は 1 球ごとの結果をすべて得点に換算して足すため、打球がヒットになったかアウトになったか、どんなカウント・走者の状況で打たれたか、といった投手の力とは別の要素も含みます。空振り率は「スイングに対して空振りか」だけを数えるので、そうした要素が入りにくい、と考えられます。被 xwOBA が run value と空振り率の間に来るのも、「ヒットになったかどうか」を外して打球の質だけを見ているためだと考えられます。

## 現場での使い方（提言）

1. **球種の評価の主役は空振り率にする**。400 球以上投げた球種なら翌年との相関は 0.70〜0.74 あり、今年の数字をそのまま来年の見込みとして使いやすい指標です
2. **run value は 1 シーズン分で良し悪しを決めない**。使うなら複数年を合わせるか、空振り率・被 xwOBA と並べて、「run value は良いが空振り率は平凡」のような食い違いがあれば、翌年は平均に近づく可能性が高いと読みます
3. **100〜199 球しか投げていない球種は、判断を保留する帯と考える**。空振り率でも相関は 0.53 にとどまります。中継ぎ投手の 3 番目の球種などを 1 年分の数字で評価するときは、特に慎重にします

## 読み方の注意

- 相関には「数字の偶然のぶれ」と「球種そのものが本当に変わった（握りを変えた、球速が落ちた等）」の両方が入っています。1 シーズンの中で数字がどれだけ正確か、を表す値ではありません。「去年の数字で来年をどれだけ言い当てられるか」として読んでください
- 800 球以上の帯は組が 401 と少なめです
- 帯は 2 シーズンのうち少ない方の球数で決めています。多い方の年は揃えていないので、同じ帯の中に片方の年だけ大きく投げている組も混ざります。また、帯によって投手の顔ぶれ（先発と中継ぎの割合など）も違うので、帯の間の差には球数の違いだけでなく顔ぶれの違いも入っています
- 2020 年（60 試合の短縮シーズン）を含む組も入れています
- 成績が落ちて翌年に登板しなくなった投手は組になりません。この選び方の偏りは補正していません
